# Reserve 1.12.3

If you use Reserve 0.9.1 or earlier, download Reserve.dmg, open it, and drag Reserve into Applications. Choose Replace, then reopen Reserve.

Reserve could refuse a third Claude account because it mistook two members of the same team for the same person. Each member can now have a separate card showing their own usage limits. If you sign in twice with the same member, Reserve tells you which card already uses that account.

If you ran into this warning, open **Settings → Providers**, select the Claude card that got stuck, and sign in again. Choose the team member you want on that card. You can keep the cards you already connected.
