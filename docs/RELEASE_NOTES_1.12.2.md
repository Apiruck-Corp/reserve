# Reserve 1.12.2

If you use Reserve 0.9.1 or earlier, download Reserve.dmg, open it, and drag Reserve into Applications. Choose Replace, then reopen Reserve.

Reserve counted 6,998 tokens in a Claude session that used 27. A tool had returned an example containing its own token counts, and Reserve added those too. Daily and hourly Insights now count the assistant’s actual usage and handle updates to the same message once.

If you switch Claude accounts, Reserve clears the old reading and shows the history from the folders that still belong to your account. Restoring a transcript or upgrading your saved history while travelling also used to double some older entries when you came home. Reserve now keeps the archived count and its saved price.

Cost estimates now require a known price for all the usage they cover. Reports include the whole first day in your local time zone. The hourly share chart shows both occurrences of 1 a.m. when clocks go back, and Grok share images and copied text show how much of the shared quota you used.

This update also includes the Claude sign-in improvements prepared for 1.12.1. If Claude Code is missing or too old, Reserve offers to install or update it before sign-in. The one-click installer works with the current Claude and Codex download addresses.

One rare date issue remains. If you upgrade old history and enter a third time zone that same day, a message near the start of the 30-day report can stay on its original date. The archive keeps the tokens. The 30-day total can briefly exclude them.
